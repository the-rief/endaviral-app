1

Database — Supabase

  1. Go to supabase.com → New project → name it endaviral

  2. Choose a strong database password and save it — you'll need it.

  3. Once created, go to Settings → Database and copy the Connection string (URI)

  4. It looks like: postgresql://postgres:[PASSWORD]@db.[REF].supabase.co:5432/postgres

  5. Change the prefix from postgresql:// to postgresql+asyncpg:// for FastAPI's async driver.

ℹ️ Keep this connection string — it becomes your DATABASE_URL environment variable.
2

Backend API — Render

2a. Push code to GitHub

cd endaviral-backend
git init
git add .
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/YOURUSERNAME/endaviral-backend.git
git push -u origin main

2b. Create Web Service on Render

  1. Go to render.com → New → Web Service

  2. Connect your GitHub repo endaviral-backend

  3. Render auto-detects render.yaml — confirm the settings:

Build Command:  pip install -r requirements.txt
Start Command:  alembic upgrade head && uvicorn app.main:app --host 0.0.0.0 --port $PORT
Region:         Frankfurt (closest to Kenya)

  1. Click Create Web Service → Render builds and deploys automatically.

  2. Your API URL will be: https://endaviral-backend.onrender.com

⚠️ Free Render services sleep after 15 minutes of inactivity. Use UptimeRobot (free) to ping /health every 5 minutes to prevent this.
3

Frontend — Netlify

Option A — Drag & Drop (fastest, no GitHub needed)

  1. Go to netlify.com → log in

  2. On the dashboard, drag the entire endaviral-pay/ folder into the dotted drop zone

  3. Netlify deploys instantly — you get a URL like https://random-name.netlify.app

  4. That's it. Done in 30 seconds.

Option B — GitHub (recommended for updates)

  1. Push the endaviral-pay/ folder to a GitHub repo

  2. Netlify → New site → Import from Git → pick your repo

  3. Build settings: leave blank (it's plain HTML, no build step needed)

  4. Every future git push auto-deploys

✅ Before deploying, edit line 1 of the <script> in index.html:
const API_BASE = 'https://YOUR-RENDER-URL.onrender.com/api/v1';

Daraja M-Pesa Setup

4a. Sandbox (for testing)

  1. Register at developer.safaricom.co.ke

  2. Go to My Apps → Create App — select Lipa Na M-Pesa Sandbox

  3. Copy your Consumer Key and Consumer Secret

  4. Sandbox shortcode: 174379, Passkey is provided in the portal

  5. Use the Daraja Simulator to test STK pushes without a real phone

4b. Production (go-live)

  1. Apply for a Paybill number at safaricom.co.ke → M-Pesa for Business

  2. In the Daraja portal, go to Go Live and submit your app for review

  3. Required documents: Business registration cert, KRA PIN, ID, M-Pesa Paybill details

  4. Once approved, get your production Consumer Key/Secret and Passkey

🚨 Compliance: When applying, describe EndaViral as a "digital marketing and online promotion platform" — NOT as a followers/engagement service. This matters heavily during Safaricom's business review.

Custom Domain Setup

Frontend — pay.endaviral.co.ke

  1. Netlify → your site → Domain settings → Add custom domain

  2. Type pay.endaviral.co.ke

  3. Netlify gives you a CNAME record, e.g.:
    pay → random.netlify.app

  4. Add this CNAME in your domain registrar's DNS

  5. Netlify auto-provisions SSL (free Let's Encrypt)

Backend — api.endaviral.co.ke

  1. Render → your service → Settings → Custom Domains

  2. Add api.endaviral.co.ke

  3. Render gives you a CNAME record to add in DNS

  4. Update DARAJA_CALLBACK_URL env var to the new domain

  5. Also update API_BASE in index.html and redeploy

⚠️ Daraja callbacks require HTTPS. Both Netlify and Render provide free SSL automatically. Never use HTTP callback URLs in production.
